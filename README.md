# 75-Day-FPGA-Digital-Design-Sprint
Executed a 75-day intensive hardware design sprint focused on FPGA architecture, Digital Design &amp; RTL coding. Progressed through an 11-week roadmap, mastering simulation in Icarus Verilog &amp; GTKWave before transitioning to Xilinx Vivado for synthesis. Designed a parameterized Synchronous FIFO and UART Transmitter system from scratch in Verilog.
